FreeBoard 白板 · 使用说明 v2.3.0

免费、离线、无广告的手写白板 / 笔记软件（仿 Notein 使用习惯）。支持手指与触控笔、多页笔记、荧光笔、套索编辑、形状、图片、文本、PDF/PPT/DOC 导入、备份恢复。

声明：本软件为独立开发的原创软件，不含 Notein 的名称、图标、素材或代码，与 Notein 无任何关联。无广告、无账号、无内购，数据只保存在你本机。

一、三种使用方式

方式 A · 安卓 APK（最方便，已签名）

1把 FreeBoard白板-v2.3.0.apk（约 3MB）用数据线 / 微信 / QQ / 网盘发到安卓手机或平板。
2点开 APK 安装；提示“未知来源 / 外部来源”时，在设置中允许本次安装即可。
3支持 Android 8.0+（minSdk 24），安装后完全离线可用。

方式 B · 网页版（iPhone / iPad / 电脑通用）

1把 FreeBoard-单文件版.html 发到设备（微信文件传输助手、邮件、AirDrop、数据线均可）。
2点开并选择“浏览器”打开（Android 建议 Chrome / Edge；iPhone/iPad 建议 Safari），直接书写，自动保存在本机。

方式 C · 装成“像 App 一样”的全屏应用

1把整个 FreeBoard 文件夹上传到任意免费静态网站（GitHub Pages、Netlify Drop、Cloudflare Pages 等）。
2手机 / 平板浏览器打开该网址后：iPhone/iPad Safari 用「分享 → 添加到主屏幕」；Android Chrome/Edge 用菜单「安装应用 / 添加到主屏幕」。
3首次打开后自动缓存，可离线使用。

二、v2.3 新增功能

  • 首页三页独立：「笔记」「文件夹」「回收站」三个标签页，各管各的
  • 六种排序：创建日期最近 / 最早、修改日期最近 / 最早、名称 A→Z、名称 Z→A，点排序按钮一键切换
  • 快速检索：搜索框支持中文、数字、英文名称关键词（同时匹配标签），边输入边筛选
  • 文件夹：修复“新建文件夹不生效”；文件夹页可新建 / 重命名 / 删除，点文件夹卡片查看其中笔记；笔记菜单「移动文件夹」归类，多选可批量移动
  • 回收站：删除笔记先进回收站，卡片可勾选多选，恢复 / 彻底删除 / 一键清空
  • 标准笔记 / 无界笔记：新建时可选：标准笔记为 A4 纸页式书写；无界笔记为无边无限画布、自由缩放书写
  • 导入创建：导入 PDF（逐页转图片）、导入 PPT（.pptx 文字与图片）、导入 DOC（.docx 文字）、导入图片（可多选）、拍照导入
  • 书写优化：切换钢笔 / 铅笔 / 荧光笔时颜色保持不变；粗细调节范围扩大到 1–32，实时预览
小提示：旧版 .ppt / .doc 请先用 Office/WPS 另存为 .pptx / .docx，或导出 PDF 后导入；PPT/DOC 以文字内容为主还原，复杂版式建议导出 PDF 逐页导入。

三、功能清单（除 AI 外全部实现）

  • 手写：钢笔 / 铅笔 / 荧光笔 / 橡皮擦（笔画级擦除，可只切断笔迹的一段）
  • 笔触：粗细 1–32、透明度、16 色 + 自定义颜色实时可调，切换笔类颜色不变
  • 双指缩放与平移、单指书写、触控笔书写自动忽略手掌（可关闭）
  • 选择编辑：套索框选、拖动、8 向手柄缩放、旋转、复制 / 粘贴、删除
  • 图层：置顶 / 置底、水平 / 垂直翻转、旋转 90°
  • 文本：点击输入、自动换行、字号 / 颜色 / 加粗 / 斜体 / 下划线 / 对齐
  • 形状：直线 / 箭头 / 矩形 / 椭圆 / 三角形 / 五角星
  • 纸张：空白 / 点阵 / 方格 / 横线 / 康奈尔 / 五线谱；深色夜读背景
  • 页面管理：新增 / 复制 / 删除 / 排序 / 缩略图面板 / 底部翻页条
  • 笔记本库：文件夹、标签、搜索、六种排序、封面颜色、重命名、多选管理
  • 图片：相册 / 拍照 / 多选插入、粘贴图片、拖入图片
  • PDF：导入（自动逐页变成白板页）、导出当前页 / 整本 PNG、导出“手写 PDF”
  • 撤销 / 重做（跨页可用）、双击放大、一键适应屏幕
  • 备份与恢复：单本或全量 JSON（换机 / 换浏览器可迁移）
  • 深浅主题、防误触等设置项；完全离线、无广告、无内购、不上传任何数据

四、常见问题

打不开或空白？ 用新版 Chrome / Edge / Safari，尽量别在微信内置浏览器中编辑。

数据会云同步吗？ 不会，仅存当前设备本地；换设备请用「备份 JSON」导出后到另一台设备恢复，或导出 PNG / PDF 分享。

能打开 Notein 笔记吗？ 不能（独立软件，格式不同），请先用 Notein 导出图片或 PDF 再导入。

升级安装？ v2.3.0 与 v2.0 / v2.1 / v2.2 同签名，可直接覆盖安装；升级前建议先「备份」以防万一。

PPT / DOC 导入不完整？ 文字内容会完整导入并自动分页；如需要与幻灯片/Word 完全一致的版式，请先导出 PDF 再导入 PDF。
