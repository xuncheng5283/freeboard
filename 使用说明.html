FreeBoard 白板 · 使用说明

免费、离线、无广告的手写白板/笔记软件 v2.2.0。

v2.2 更新：点阵/方格/横线/五线谱图案全幅铺满，方格为正方形；可在“纸张模板”中自由更改图案颜色；顶部新增“清空本页”一键清屏（可撤销）；钢笔 / 铅笔 / 荧光笔按真实书写效果区分（粗细、透明度、纹理各不相同）。

支持手指与触控笔、多页笔记、荧光笔、套索编辑、形状、图片、文本、PDF 导入导出、备份恢复。

声明:本软件为独立开发的原创软件，不含 Notein 的名称、图标、素材或代码，与 Notein 无任何关联。

一、三种使用方式

方式 A · 安卓 APK（最方便，已签名）

1把 FreeBoard白板-v2.2.0.apk（约 2.9MB）用数据线 / 微信 / QQ / 网盘发到安卓手机或平板。
2点开 APK 安装；提示“未知来源/外部来源”时，在设置中允许本次安装即可。
3支持 Android 8.0+（minSdk 24）。安装后完全离线可用，数据只存本机。

方式 B · 网页版（iPhone / iPad / 电脑通用）

1把 FreeBoard-单文件版.html 发到设备（微信文件传输助手、邮件、AirDrop、数据线均可）。
2点开并选择“浏览器”打开（Android 建议 Chrome / Edge；iPhone/iPad 建议 Safari），直接书写，自动保存在本机。

方式 C · 装成“像 App 一样”的全屏应用

1把整个 FreeBoard 文件夹上传到任意免费静态网站（GitHub Pages、Netlify Drop、Cloudflare Pages 等）。
2手机/平板浏览器打开该网址。
3iPhone/iPad Safari：分享 →「添加到主屏幕」；Android Chrome/Edge：菜单 →「安装应用/添加到主屏幕」，首次打开后会自动缓存、可离线用。

二、功能清单（除 AI 外已全部实现）

  • 手写：钢笔 / 铅笔 / 荧光笔 / 橡皮擦（笔画级擦除，可只切断笔迹的一段）
  • 笔触：粗细、透明度、16 色 + 自定义颜色实时可调
  • 双指缩放与平移、单指书写、触控笔书写自动忽略手掌（可关闭）
  • 选择编辑：套索框选、拖动、8 向手柄缩放、旋转、复制 / 粘贴、删除
  • 图层：置顶 / 置底、水平 / 垂直翻转、旋转 90°
  • 文本：点击输入、自动换行、字号 / 颜色 / 加粗 / 斜体 / 下划线 / 对齐
  • 形状：直线 / 箭头 / 矩形 / 椭圆 / 三角形 / 五角星
  • 纸张：空白 / 点阵 / 方格 / 横线 / 康奈尔 / 五线谱；多种深色夜读背景
  • 页面管理：新增 / 复制 / 删除 / 拖拽排序 / 缩略图面板 / 底部翻页条
  • 笔记本库：多本白板、文件夹、标签、搜索、排序、封面颜色、重命名
  • 图片：相册 / 拍照 / 多选插入、粘贴图片、拖入图片
  • PDF：导入（自动逐页变成白板页）、导出当前页 / 整本 PNG、导出“手写 PDF”
  • 撤销 / 重做（跨页可用）、双击放大、一键适应屏幕
  • 备份与恢复：单本或全量 JSON（换机 / 换浏览器可迁移）
  • 深浅主题、防误触等设置项；完全离线、无广告、无内购、不上传任何数据

三、常见问题

打不开或空白? 用新版 Chrome / Edge / Safari，尽量别在微信内置浏览器中编辑。

数据会云同步吗? 不会，仅存当前设备本地；换设备请用“备份 JSON”导出后到另一台设备恢复，或导出 PNG / PDF 分享。

能打开 Notein 笔记吗? 不能（独立软件，格式不同），请先用 Notein 导出图片或 PDF 再导入。

安卓触摸写不了 / 纸张空白 / 打不开已保存白板? 请更新到 v2.2 安装包（同签名可直接覆盖安装），相关问题已修复。

装了旧版? 1.0 版请先卸载再安装（数据格式升级）；v2.0 升 v2.1 可直接覆盖安装。升级前建议先用“备份”导出以防万一。
