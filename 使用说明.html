FreeBoard 白板 · 使用说明 v2.3.4

免费、离线、无广告的手写白板 / 笔记软件（仿 Notein 使用习惯）。支持手指与触控笔、多页笔记、文件夹归类、回收站、六种排序与检索、荧光笔、套索编辑、形状、图片、文本、PDF/PPT/DOC 导入、备份恢复。

声明：本软件为独立开发的原创软件，不含 Notein 的名称、图标、素材或代码，与 Notein 无任何关联。无广告、无账号、无内购，数据只保存在你本机。

一、三种使用方式

方式 A · 安卓 APK（最方便，已签名）

1把 FreeBoard白板-v2.3.4.apk（约 3MB）用数据线 / 微信 / QQ / 网盘发到安卓手机或平板。
2点开 APK 安装；提示“未知来源 / 外部来源”时，在设置中允许本次安装即可。
3支持 Android 8.0+（minSdk 24），安装后完全离线可用。

方式 B · 网页版（iPhone / iPad / 电脑通用）

1把 FreeBoard-单文件版.html 发到设备（微信文件传输助手、邮件、AirDrop、数据线均可）。
2点开并选择“浏览器”打开（Android 建议 Chrome / Edge；iPhone/iPad 建议 Safari），直接书写，自动保存在本机。

方式 C · 装成“像 App 一样”的全屏应用

1把整个 FreeBoard 文件夹上传到任意免费静态网站（GitHub Pages、Netlify Drop、Cloudflare Pages 等）。
2手机 / 平板浏览器打开该网址后：iPhone/iPad Safari 用「分享 → 添加到主屏幕」；Android Chrome/Edge 用菜单「安装应用 / 添加到主屏幕」。
3首次打开后自动缓存，可离线使用。

二、v2.3.4 更新内容

  • 文件夹归属：在文件夹内点「新建」（包括 PDF / PPT / DOC / 图片 / 拍照导入），新笔记会直接归入该文件夹，同时出现在「全部」和该文件夹中
  • 文件夹标签：每张笔记卡片显示所属文件夹标签（未分类则显示“未分类”），点文件夹标签可一键筛选该文件夹的笔记
  • 未分类笔记：首页创建的未分类笔记，同时出现在「全部」与「未分类」栏
  • 文件夹回收站：删除文件夹时，文件夹与其内全部笔记一起移入回收站新增的「文件夹」栏，名称与内容完整保留，可整组恢复或彻底删除；恢复时遇同名文件夹自动改名（如 数学（2））
  • 手动排序：排序菜单新增「手动排序（长按拖动）」，选择后长按笔记卡片拖动到目标位置即可排序，卡片间有蓝色插入线提示
  • 稳定性：修复重启后“文件夹”形态回收站内容丢失；修复回收站单条恢复 / 彻底删除后未即时保存与刷新界面的问题

三、功能清单（除 AI 外全部实现）

  • 首页三页独立：笔记 / 文件夹 / 回收站；笔记卡片文件夹标签可点击筛选
  • 排序：手动排序（长按拖动）、创建日期最近 / 最早、修改日期最近 / 最早、名称 A→Z、名称 Z→A
  • 搜索：中文 / 数字 / 英文名称关键词与标签即时检索
  • 文件夹：新建 / 重命名 / 删除（连同笔记进回收站）、点文件夹查看内容、笔记菜单「移动文件夹」、多选批量移动
  • 回收站：「笔记 / 文件夹」两栏，勾选多选恢复或彻底删除、一键清空
  • 新建：标准笔记（A4 纸页式）/ 无界笔记（无边画布）
  • 导入创建：PDF（逐页转图片）、PPT（.pptx 文字与图片）、DOC（.docx 文字）、图片（多选）、拍照导入
  • 手写：钢笔 / 铅笔 / 荧光笔 / 橡皮擦（笔画级擦除）；切换笔类颜色不变；粗细 1–32 实时可调
  • 双指缩放与平移、单指书写、触控笔书写自动忽略手掌（可关）
  • 选择编辑：套索框选、拖动、8 向手柄缩放、旋转、复制 / 粘贴、删除
  • 图层：置顶 / 置底、水平 / 垂直翻转、旋转 90°；文本 / 形状 / 多种纸张模板、深色夜读背景
  • 页面管理：新增 / 复制 / 删除 / 排序 / 缩略图面板 / 底部翻页条
  • 导出：当前页 / 整本 PNG、手写 PDF；备份与恢复 JSON（换机 / 换浏览器可迁移）
  • 启动异常自动进入修复页（一键重载或清空数据重试），不再白屏闪退；完全离线、无广告、无内购、不上传任何数据

四、常见问题

打不开或空白？ 用新版 Chrome / Edge / Safari，尽量别在微信内置浏览器中编辑。

数据会云同步吗？ 不会，仅存当前设备本地；换设备请用「备份 JSON」导出后到另一台设备恢复，或导出 PNG / PDF 分享。

能打开 Notein 笔记吗？ 不能（独立软件，格式不同），请先用 Notein 导出图片或 PDF 再导入。

升级安装？ v2.3.4 与 v2.0 ~ v2.3.3 同包名（com.freeboard.app）同签名，可直接覆盖安装并保留笔记；升级前建议先「备份」以防万一。若你装的是 v2.3.0 ~ v2.3.2（坏包名、点开就崩），请先卸载再装本版。

PPT / DOC 导入不完整？ 文字内容会完整导入并自动分页；如需要与幻灯片/Word 完全一致的版式，请先导出 PDF 再导入 PDF。
