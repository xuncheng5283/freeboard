FreeBoard 白板 · 使用说明

免费、离线、无广告的手写白板/笔记软件。支持手指与触控笔、多页笔记、荧光笔、橡皮擦、双指缩放移动、自动保存与导出 PNG。

说明:本软件为独立开发的原创软件,不含 Notein 的名称、图标、素材或代码,与 Notein 无任何关联。

一、三种使用方式

方式 A · 手机/平板直接打开(最简单)

1把压缩包里的 FreeBoard-单文件版.html 发到手机/平板(微信文件传输助手、邮件、数据线、AirDrop 均可)。
2在手机上点开该文件,选择「浏览器」打开(Android 建议 Chrome / Edge;iPhone / iPad 建议 Safari)。
3直接书写,内容自动保存在设备本地;下次打开同一文件即可继续。

方式 B · 装成“像 App 一样”(体验最佳)

1把整个 FreeBoard 文件夹上传到任意免费静态网站(GitHub Pages、Netlify Drop、Vercel 等)。
2手机/平板浏览器打开该网址。
3iPhone/iPad Safari:分享 →「添加到主屏幕」;Android Chrome/Edge:菜单 →「安装应用/添加到主屏幕」。
4主屏幕出现图标即为全屏离线应用(首次打开会自动缓存)。

方式 C · 电脑上

双击 index.html 即可;也可让平板手机与本机同一 Wi-Fi 后访问电脑上托管的该文件夹。

二、功能

- 钢笔 / 铅笔 / 荧光笔 / 橡皮擦 / 抓手;16 色 + 自定义颜色,粗细、透明度可调
- 单指书写;双指捏合缩放、双指拖动平移;触控笔书写自动忽略手掌
- 多页面管理:新增 / 复制 / 删除 / 缩略图
- 纸张:空白 / 点阵 / 方格 / 横线 / 深色夜读
- 多本白板:新建 / 打开 / 重命名 / 删除,自动保存
- 导出当前页 PNG、整本长图 PNG
- 完全离线、无广告、无内购、不上传任何数据

三、常见问题

打开后空白或无法保存? 使用新版 Chrome / Edge / Safari,尽量别在微信内置浏览器中编辑。

数据会自动同步吗? 不会,仅存当前设备本地;跨设备可用导出 PNG 分享。

能打开 Notein 笔记吗? 不能(独立软件、私有格式不同),请用 Notein 导出图片后整理。
